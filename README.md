One funny, painfully honest line imagining the comment a developer left
above fragile production code.

## Entry

```text
// getUserById() takes no id, hits no database, returns no user. The name is aspirational.
```

## Run

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (and prints it to stdout).
